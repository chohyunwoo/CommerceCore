# Commerce Core — 1차 개인 프로젝트 제출 (백엔드)

> **한 줄 요약**: AI 이미지 유사도 검색 기능을 갖춘 **서비스급 이커머스 백엔드 API**.
> 입력 검증·구조화 에러·인증(RBAC)·요청 한도·캐시·요청 로깅을 갖추고, **비관적 락으로 재고 초과 판매를 원천 차단**하며,
> 부하 테스트로 **병목을 진단해 처리량 +60% / p95 −38%로 개선**한 과정을 수치로 증명한다.
